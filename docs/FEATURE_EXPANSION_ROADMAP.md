# WinOptimizer — Lộ Trình Mở Rộng Tính Năng Nâng Cao (Dựa trên Open-Source Research)

## 🎯 Danh sách tính năng đề xuất:

1. **Duplicate File Finder** (Tìm file trùng lặp bằng SHA-256)
2. **Registry Tweaks Manager** (Performance, Privacy, GPU, Network)
3. **Advanced GPU Optimization Panel** (NVIDIA/AMD/Intel tweaks)
4. **Telemetry & Privacy Hardening Suite** (Chặn telemetry, tracking domains)
5. **Startup & Service Manager Nâng Cao** (Phân lớp impact, delayed startup)
6. **Windows Update & Delivery Optimization Controller**
7. **System Benchmark & Performance Monitor** (Đo lường trước và sau khi tối ưu)
8. **Profile-Based Optimization System** (Gaming, Privacy, Battery Saver, v.v.)
